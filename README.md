# Currency Converter

A simple currency converter web app built with HTML, CSS, and JavaScript, using a free exchange rate API to convert between currencies.

## 🔗 Live Demo
[https://ronitkp06-proj.github.io/currency-converter/](https://ronitkp06-proj.github.io/currency-converter/) *(enable GitHub Pages in repo Settings → Pages to activate this link)*

## 📌 About the Project

This project lets users convert an amount from one currency to another using exchange rate data pulled from a free public API. It was built to practice working with external APIs, handling asynchronous JavaScript (fetch/promises), and building a clean, functional UI around real data.

## ✨ Features

- Convert between multiple world currencies
- Dropdown selection for "from" and "to" currencies
- Fetches exchange rate data from a free API
- Instant conversion result on input
- Simple, responsive UI

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Fetch API)
- Free currency exchange rate API *(rates on the free tier update periodically rather than in real-time)*

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/ronitkp06-proj/currency-converter.git

# Navigate into the project folder
cd currency-converter

# Open index.html in your browser
```

No additional installation or dependencies are required to use it.

## 💱 How to Use

1. Enter the amount you want to convert
2. Select the currency you're converting from
3. Select the currency you're converting to
4. View the converted amount instantly
